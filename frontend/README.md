# HabitTrackerApp Frontend

This folder contains the React-based user interface for the HabitTrackerApp.

### Directory Audit & Essentials

- **Entry point:** `src/index.js` renders `<App />`, which manages routes for `/`, `/login`, `/register`, `/dashboard`.
- **Main source:** Full application resides in `src/` (no `public/` folder is present), meeting CRA placement.
- **Themes & styles:** CSS variables, system palette, and style sheet present (`styles/theme.css`, `index.css`, `Dashboard.module.css`).
- **Major pages/components:** `App.js`, `Dashboard.js`, `Login.js`, `Register.js`, with proper subfolder re-exports.
- **Mock data:** Local demo JSON (`quotes.json`) included for offline prototyping. Real data expected from `/database` at runtime.
- **Dependencies:** All essential dependencies in `package.json` (`react`, `react-dom`, `react-scripts`, `axios`, `react-router-dom`).
    - Ensure that during deployment, a `public/` folder exists with an `index.html` as required by CRA.

## Scripts

- `npm install` — Install dependencies
- `npm start` — Start development server at `localhost:3000`
- `npm run build` — Build for production

## Structure

- `src/` — React source files, components, modules, demo data, and stylesheets
- `styles/` — Local theme/style guides
- No explicit `public/` directory (may be generated by build step)
